# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

**上报必须绑定有效的仪器校准证。** 校准证记仪器编号和有效截止日；截止日当天仍有效，过期或已作废的证不能上报。检查员可新建证、改截止日、作废证；旁观账号只能翻证册。顶栏入口叫「校准证」。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可建证/改证/作废证 |
| viewer | view123456 | 只能看记录、翻证册 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，顶栏点「校准证」，新建一张截止日在未来的证；回到班测页选这张证上报 0.4，应放行（正常），记录带仪器编号。
2. 回「校准证」把这张证的截止日改到昨天并保存，再用这张证上报，应被拒绝，原因写明校准证已过期。
3. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
4. viewer 登录后没有上报表单、没有新建证表单（证册可翻），直接调上报/建证接口返回 403。
